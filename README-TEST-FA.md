# راهنمای آزمایش امن نسخهٔ مسیر (فارسی)

## مهم: این نسخه هنوز آمادهٔ اتصال نیست
برای محافظت از حسابداری واقعی، اطلاعات Firebase اصلی از این نسخه حذف شده و با عبارت‌های `REPLACE_WITH_TEST_...` جایگزین شده است. تا وقتی تنظیمات Firebase آزمایشی را وارد نکنی، برنامه عمداً اجرا نمی‌شود. این رفتار حفاظتی است، نه خرابی برنامه.

## روش پیشنهادی
1. در Firebase Console یک پروژهٔ جدید و جدا بساز؛ نام پیشنهادی: `hesabdari-route-test`. پروژهٔ `motar-pakhsh` را انتخاب نکن.
2. در پروژهٔ آزمایشی، Authentication را فعال کن و روش ورود Email/Password را روشن کن.
3. یک برنامهٔ Web در تنظیمات پروژه اضافه کن و مقادیر Firebase config را کپی کن.
4. در `app.js` فقط شیء `firebaseConfig` را با مقادیر پروژهٔ آزمایشی جایگزین کن. `projectId` باید شناسهٔ پروژهٔ آزمایشی باشد، نه `motar-pakhsh`.
5. در Firestore Database یک دیتابیس بساز. ابتدا فقط قوانین همین پروژهٔ آزمایشی را از فایل `firestore.rules` منتشر کن.
6. این برنامه به نقش کاربر در `businesses/main/team/{uid}` نیاز دارد. قبل از ورود، باید کاربر آزمایشی ساخته شود و سند تیم مطابق ساختار برنامه برای همان UID ایجاد شود. در قوانین فعلی نقش owner علاوه بر `role: owner` به ایمیل `manager@motar.com` وابسته است؛ برای همین، یا از حساب آزمایشی با همین ایمیل استفاده کن، یا قوانین آزمایشی را با احتیاط برای ایمیل آزمایشی خودت تنظیم کن. هرگز این تغییر را بی‌بررسی در پروژهٔ اصلی منتشر نکن.
7. پس از جایگزینی تنظیمات، اجرا کن: `npm test` (نیازمند Node.js). سپس مخزن جداگانه بساز و این پوشه را در شاخهٔ `main` بارگذاری کن تا GitHub Actions آن را در GitHub Pages منتشر کند.

## اصلاح‌های انجام‌شده در این بسته
- تنظیمات Firebase اصلی حذف شده تا آزمایش ناخواسته روی دیتابیس واقعی انجام نشود.
- مسیر فونت ناموجود از فهرست فایل‌های اجباری Service Worker حذف شده؛ فونت جایگزین سیستم استفاده می‌شود.
- گردش انتشار GitHub Actions اکنون `BUILD_ID` را با شناسهٔ commit جایگزین می‌کند تا کش نسخه‌ها به‌درستی تفکیک شود.
- دستور تست قوانین حذف شده، چون `tests/rules.test.mjs` در بستهٔ تحویلی وجود نداشت. این به معنی تست‌شدن قوانین نیست.

## چه چیزهایی هنوز تأیید نشده‌اند
- تست در مرورگر یا گوشی واقعی.
- آزمون قوانین Firestore با Emulator یا پروژهٔ واقعی.
- قطع و وصل اینترنت و همگام‌سازی روی دستگاه واقعی.
- سازگاری کامل نقش‌ها در Firebase آزمایشی.
